# DaleelAI visual direction

Inspected the current Vite/React shell, chat stream, citations, calculator, filer, notice, checklists, experts, updates, evaluation, and privacy screens. Behavior stays on the existing APIs. No accounts, no new tax math.

## What the references contribute

- Linear: tight type, quiet borders, one accent, almost no decoration.
- Perplexity: the answer is the page; sources are readable cards, not stamps.
- ChatGPT: a calm thread, a composer that stays put, suggestions before the first message.
- Mercury: financial trust comes from numbers, spacing, and plain language, not from a dark brand wall.
- Vercel: precise alignment and short motion. Entrances do not bounce.

## Adapted for DaleelAI

Warm paper canvas, deep ink text, emerald only for the primary action, verified answers, and the mark. The sidebar is a light column. The welcome screen is editorial: one headline, one document illustration, six real questions. Citations stay tied to backend sources.

## Avoided

A full green sidebar, gold rules, purple gradients, glass cards, stock photos, invented rates, and a motion library. CSS handles the short entrances. `prefers-reduced-motion` already collapses them.

## Motion

180–240ms ease-out on color and the welcome stagger. Skeleton shimmer only while an answer has no text yet. The mobile drawer still slides on transform.
